# Sources specification

The vertical slice preserves `Source`, `SourceRecord`, `Claim`, and
`ClaimSource`. A source stores publisher, title, type, URL, publication date,
retrieval time, optional document hash, and optional storage reference. A
source record identifies the relevant portion of that source; a claim captures
the displayed project fact and `ClaimSource` links it to evidence.

The seed dataset uses clearly labelled fictional demonstration sources. They
are not official government records and are never represented as such.
